# Задача: Интеграция AmneziaWG и MTProxy через прямое SSH-управление
## Концепт и Главное правило
Мы полностью отказываемся от использования промежуточной PHP-панели (`amneziavpnphp`) в пользу прямого управления VPN-серверами по SSH напрямую из Python-бота.
**Главное правило:** Все методы работы с сервером (первоначальная настройка, установка Docker, установка протоколов, добавление и удаление клиентов) должны быть реализованы **в точности так, как это делает оригинальное десктопное приложение Amnezia**. Никакой отсебятины и удаления интерфейсов: полная совместимость с оригинальными `.sh` скриптами Amnezia.
## Архитектурное решение и Интеграция
1. **Библиотека**: Использовать `asyncssh` для асинхронного выполнения команд на сервере.
2. **Структура БД (Модели)**:
   - В таблицу `Server` (или связанную `ServerConfig`) добавить поля для SSH-доступа: `ssh_user`, `ssh_password` (зашифрованный через Fernet, аналогично паролям XUI), `ssh_port`, `ssh_key` (опционально).
3. **Модули провайдеров (`app/services/vpn_providers/`)**:
   - Внедрить абстрактный интерфейс `BaseVPNProvider`.
   - Создать `AmneziaAWGProvider` (для работы с AWG/AWG2).
   - Создать `MTProxyProvider` (для работы с Telegram MTProxy).
   - Существующую интеграцию с XUI обернуть в `XUIProvider` для единого стандарта.
## Пошаговый алгоритм для AmneziaWG (AWG/AWG2)
### Добавление клиента (`create_client`)
1. **SSH-подключение**: Установить соединение через `asyncssh`.
2. **Генерация ключей** (через контейнер):
   - Приватный ключ: `docker exec -i amnezia-awg awg genkey`
   - Публичный ключ: `docker exec -i amnezia-awg bash -c 'echo "<private_key>" | awg pubkey'`
3. **Поиск свободного IP**:
   - Считать конфиг: `docker exec -i amnezia-awg cat /opt/amnezia/awg/awg0.conf`
   - Распарсить все значения `AllowedIPs` в блоках `[Peer]`.
   - Вычислить следующий свободный IP.
4. **Добавление пира в файл**:
   - Сформировать текстовый блок:
     ```ini
     [Peer]
     PublicKey = <public_key>
     PresharedKey = <psk_key_from_server>
     AllowedIPs = <new_ip>/32
     ```
   - Дописать в конфиг: `docker exec -i amnezia-awg bash -c 'echo -e "\n<блок>" >> /opt/amnezia/awg/awg0.conf'`
5. **Синхронизация "на лету" (Как в оригинале)**:
   - Выполнить команду применения конфигурации без разрыва и удаления интерфейса:
     `docker exec -i amnezia-awg bash -c 'awg syncconf awg0 <(awg-quick strip /opt/amnezia/awg/awg0.conf)'`
6. **Генерация конфига для юзера**:
   - Бот локально собирает текстовый файл `.conf` с настройками интерфейса (ключи, IP, параметры обфускации Jc, Jmin, S1, H1 и т.д.) и генерирует QR-код (через `qrcode` или `segno`).
### Удаление клиента (`delete_client`)
1. Выполнить команду мгновенного удаления из ядра:
   `docker exec -i amnezia-awg awg set awg0 peer <public_key> remove`
2. Считать `/opt/amnezia/awg/awg0.conf` через SSH, распарсить текст в Python, удалить весь блок `[Peer]`, относящийся к удаляемому ключу.
3. Перезаписать файл на сервере (сохраняя консистентность после перезагрузок контейнера).
## Алгоритм для MTProxy
1. За основу скрипта установки/генерации контейнера можно взять готовый скрипт из PHP-панели.
2. При добавлении/удалении секрета:
   - Бот по SSH редактирует `config.json` (или env-переменные) контейнера.
   - Выполняет мягкий рестарт контейнера: `docker restart mtproxy`.
   - Возвращает юзеру готовую ссылку `tg://proxy?server=...`.
## План на будущее: Автоматизация 3x-ui
В дальнейшем функционал прямого SSH-управления будет расширен для полной автоматизации 3x-ui:
1. **Первичная установка 3x-ui серверов**: Бот должен уметь самостоятельно поднимать XUI панель на "голом" Ubuntu/Debian сервере. 
2. Скрипт установки 3x-ui уже существует, но его потребуется доработать (сделать неинтерактивным, захардкодить или генерировать логин/пароль/порт базы для панели и сохранять в БД бота).
3. Таким образом, весь цикл от покупки VPS до выдачи конфигураций пользователю будет полностью замкнут в Telegram-боте без ручных действий.
## Задачи для разработчика (Текущий Спринт)
1. Установить зависимость: `pip install asyncssh cryptography qrcode`
2. Расширить модель сервера (`app/database/models/server.py`) полями для SSH: `ssh_port` (default 22), `ssh_user` (default root), `ssh_password` (зашифрованный Fernet).
3. Создать пакет `app/services/vpn_providers/`.
4. Реализовать классы `AmneziaAWGProvider` и `MTProxyProvider`, инкапсулирующие логику выполнения команд через `asyncssh`.
5. Интегрировать эти провайдеры в `SubscriptionService` бота, связав их с логикой выдачи подписок.
6. Вырезать все рудименты интеграции с `amneziavpnphp`, если они успели попасть в текущую ветку.
## Меры предосторожности
- Использовать экранирование спецсимволов при передаче ключей в `bash -c`.
- Внимательно парсить конфигурацию (учитывать переносы строк `\r\n` и `\n`).
- Сохранять совместимость с названиями контейнеров и интерфейсов (например `awg2` использует `awg0.conf` и интерфейс `awg0`).
